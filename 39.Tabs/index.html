HTML

The standard language used to structure the content of web pages, like headings, paragraphs, and images. It defines what elements appear on a webpage.

CSS

A language used to style HTML elements, controlling layout, colors, fonts, and overall design of web pages

JS

A programming language that makes web pages interactive, like responding to clicks, form validation, or animations.

REACT

A JavaScript library for building user interfaces, especially dynamic single-page applications (SPAs), using reusable components.

NodeJS

A runtime environment that lets you run JavaScript on the server, enabling backend development and building full-stack applications.
