• HTML stands for HyperText Markup Language. It is used to create the structure of web pages using tags and elements.

  • CSS stands for Cascading Style Sheets. It is used to style HTML elements and control layout, colors, fonts, and spacing.

  • JavaScript is a programming language that makes web pages interactive. It can manipulate HTML elements, handle events, and communicate with servers.

  • Node.js is a runtime environment that allows JavaScript to run on the server. It enables building scalable backend applications.

  • The DOM (Document Object Model) is a programming interface for web documents. It represents the page so scripts can change structure, style, and content dynamically.

  • An API (Application Programming Interface) allows different software applications to communicate with each other. Web APIs often provide data from servers to client applications.

  • Git is a version control system that tracks changes in files and allows multiple developers to collaborate on a project efficiently.

  • JSON (JavaScript Object Notation) is a lightweight data format used to exchange data between a server and a client. It is easy for humans to read and write.
